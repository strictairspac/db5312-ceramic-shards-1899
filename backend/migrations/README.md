# 结构说明

`src/models/tables.py` 定义关系结构。API 启动时显式创建演示库的表（`schema.create_all`），此版本仍不包含版本化迁移；已有部署升级时，新增的交班表可随启动自动创建，历史数据无需回填。

## 交班相关表

| 表 | 作用 |
| --- | --- |
| `handover_outbox` | 事务性发件箱。试算报告与复核签字在业务事务内登记，与业务写入同成同败。`seq` 单调递增且唯一。 |
| `handover_ledger` | 交班账。全班组共享，每个事件只记一次；`outbox_id` 与 `seq` 唯一，重复投递不会重复记。 |
| `handover_cursors` | 每班组一条游标，记录已确认到的 `last_seq`；只由该班组推进。 |
| `handover_sequence` | 单行计数，用于分配提交顺序。`UPDATE` 持锁到事务提交，保证 seq 顺序即提交顺序。 |

升级到本版本不需要改历史行：证据首次被复核时，若尚无报告登记会自动补记报告（`ensure_report`），保证交班账里报告先于签字。
